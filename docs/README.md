# PRD Digital Posyandu

Paket dokumen kebutuhan produk untuk konsep aplikasi digitalisasi pencatatan dan administrasi Posyandu.

## Isi paket
- `docs/01-PRD.md` — Product Requirements Document utama.
- `docs/02-User-Stories-Acceptance-Criteria.md` — user stories dan kriteria penerimaan.
- `docs/03-Information-Architecture-and-User-Flows.md` — struktur menu dan alur utama.
- `docs/04-Data-Dictionary.md` — rancangan entitas dan data.
- `docs/05-AI-Summary-and-RAG-Safety.md` — spesifikasi AI ringkasan, rekomendasi edukatif, dan chatbot RAG opsional.
- `docs/06-MVP-Roadmap-and-Success-Metrics.md` — prioritas MVP, roadmap, dan metrik.
- `docs/07-Risks-Assumptions-and-Validation.md` — risiko, asumsi, validasi lapangan.
- `REFERENCES.md` — referensi resmi dan catatan kebijakan.

## Cara menggunakan
1. Jadikan `01-PRD.md` sebagai dokumen acuan utama tim.
2. Konfirmasi alur kerja dengan minimal satu kader dan satu tenaga kesehatan/Puskesmas.
3. Validasi formulir, indikator, standar pertumbuhan, jadwal imunisasi, dan isi edukasi sebelum demo yang menggunakan data kesehatan nyata.
4. Untuk lomba, gunakan data dummy sintetis. Jangan memasukkan identitas atau rekam kesehatan anak sungguhan ke lingkungan demo.

## Prinsip produk
Aplikasi ini membantu pencatatan, pengelolaan, dan komunikasi informasi Posyandu. Aplikasi **bukan alat diagnosis**, bukan pengganti Buku KIA, bukan pengganti keputusan tenaga kesehatan, dan tidak boleh mengubah catatan klinis secara otomatis.
